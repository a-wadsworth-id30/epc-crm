Manual Test Steps

Step 1
All features on

Config should show enabled flags. Phone numbers should change if the CRM has an active tracking number or fallback number. The safe form should contain a hidden crm_attribution input.

Step 2
Disable phone replacement

Refresh this page. The phone endpoint should not assign a number and the visible numbers should remain 01234 567890.

Step 3
Disable hidden field injection

Refresh this page. The form should no longer contain a hidden crm_attribution input.

Step 4
Disable attribution script

Refresh this page. Config should show the script disabled, and no capture, form injection or phone replacement should run.

Step 5
Require consent

Enable consent gating, refresh this page, then use Grant consent. Capture, form injection and phone replacement should begin after consent is granted.
